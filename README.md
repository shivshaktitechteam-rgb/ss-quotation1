# Quotation App (GitHub Pages) + Google Sheets (Apps Script API)

## 1) Paste Apps Script Web App URL
Open `api.js` and set:
`const API_BASE = "https://script.google.com/macros/s/....../exec";`

## 2) Enable GitHub Pages
Repo -> Settings -> Pages -> Deploy from branch -> main -> /(root)

## Notes
- Desktop: table UI like your screenshot
- Mobile: card UI (Option B)
